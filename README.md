  <h1>Cairn</h1>
  <p>An intentional step towards a more responsible web.</p>
</div>

<br />

Cairn is a starting point for responsible web experiences, made by [Driftime®](https://driftime.com) and shaped by the belief that building with intentionality should feel like the natural path, not the harder one. It brings together the tooling, structure, and patterns we've refined across real Next.js and Sanity projects — defaults chosen to prioritise sustainability, performance, accessibility, and ergonomics. Like its namesake, Cairn is set with care to guide the way. It's opinionated about how things are built, not what gets built, because we've learned that where something begins defines everything that follows.
